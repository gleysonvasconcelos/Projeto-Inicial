# 🪪 Agregador de Links (DevLinks)

Uma página web moderna e responsiva no estilo *Linktree*, desenvolvida para centralizar e compartilhar links de redes sociais e projetos em um só lugar.

## 🚀 Tecnologias Utilizadas

- **HTML5**: Estruturação semântica do projeto
- **CSS3**: Estilização, animações e layout responsivo
- **JavaScript**: Lógica para alternância de tema (Light/Dark mode)

## ✨ Funcionalidades

- Lista de links personalizados para redes sociais
- Alternância de tema claro/escuro com suporte a animações
- Design focado na experiência do usuário em dispositivos móveis e desktop
